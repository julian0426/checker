고객사별 매출 금액 대조 프로그램

[목표 실행 환경]
- 최종 사용자 PC: Python 설치 불필요
- 최종 사용자 PC: 별도 라이브러리 설치 불필요
- Windows용 단일 EXE로 실행
- 원본 엑셀은 읽기만 하며 수정하지 않음

[EXE 생성 - Python을 직접 설치하지 않는 방법]
이 패키지에는 GitHub Actions 자동 빌드 설정(.github/workflows/build-windows.yml)이 포함되어 있습니다.
GitHub의 Windows 빌드 서버가 EXE를 만들므로, 사용자 PC에 Python을 설치할 필요가 없습니다.

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 ZIP의 압축을 푼 파일 전체를 저장소에 업로드합니다. .github 폴더도 반드시 포함합니다.
3. 저장소의 Actions 탭에서 'Build Windows EXE' 작업을 선택하고 'Run workflow'를 누릅니다.
4. 작업이 완료되면 실행 기록 하단의 Artifacts에서 '고객사별_금액대조-Windows'를 다운로드합니다.
5. 다운로드한 ZIP을 풀면 고객사별_금액대조.exe가 있습니다.
6. 이 EXE는 Python이 설치되지 않은 Windows PC에서도 실행하도록 단일 파일로 패키징됩니다.

[EXE 생성 - Windows 개발 PC에서 직접 빌드하는 방법]
Python 3가 설치된 Windows PC에서 build.bat을 실행하면 dist 폴더에 EXE가 생성됩니다.
이때 Python은 빌드 PC에만 필요하고, 완성된 EXE를 사용하는 PC에는 필요하지 않습니다.

[사용 방법]
1. 프로그램 실행 후 '엑셀 업로드'를 누릅니다.
2. 원본 엑셀의 고객사별 집계가 표시됩니다.
3. 각 고객사 행에서 과세(입력), 면세(입력), 인보이스(입력) 칸을 더블클릭해 제출 금액을 입력합니다.
4. 차액은 제출 금액 - 엑셀 집계 금액으로 계산됩니다.
5. '비교 결과 엑셀 저장'으로 결과를 저장합니다.
6. 제출 금액이 없는 항목이 하나라도 있으면 해당 고객사는 '미입력'으로 표시됩니다.

[집계 규칙]
- AQ열(43번째): 매출마감대상금액
- AV열(48번째): 고객사명
- AB열(28번째): 과세/면세
- BG열(59번째): 수주유형코드
- 과세: BG=801 주문(+), BG=811 취소(-), AB=과세
- 면세: BG=801 주문(+), BG=811 취소(-), AB=면세
- 인보이스: BG=851 주문(+), BG=861 취소(-)
- 주문 금액은 양수, 취소 금액은 음수로 정규화합니다.
- 해당 코드 외의 행은 집계에서 제외합니다.
- 첫 행이 제목이어도 코드가 대상 코드가 아니므로 자동으로 제외됩니다.

[주의]
- 현재 실행 환경은 Linux이므로 여기서 Windows EXE 바이너리를 직접 컴파일할 수 없습니다.
- GitHub Actions 방식은 Windows 빌드 서버에서 EXE를 생성하는 대안입니다.
- GitHub 저장소에 업무용 원본 엑셀 파일을 업로드하지 마세요. 소스 파일만 업로드하면 됩니다.
